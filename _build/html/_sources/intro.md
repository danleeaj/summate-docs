# Welcome to `summate_ai`

`summate_ai` is an auto-grading framework designed to grade rubric-based natural language student responses. We utilize small large language models (LLMs) to ensure all data flow is controlled by the user. This means the grader can be run completely locally, without internet access. However, this also means that the grader is resource-heavy. All tests were performed on an M1 MacBook Pro.

You can visit our repository [here on Github](https://github.com/danleeaj/summate-ai).

The following will guide you through how to install and get started. At the moment, some basic proficiency in Python is required as our interface is not very user-friendly yet.
